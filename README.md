# Output

> 이 프로젝트는 개인이 만든 비공식 소프트웨어이며, Creator Micro 제조사, Orca(Stably AI), OpenAI(ChatGPT·Codex), Apple 등 언급된 어떤 회사와도 관계가 없고 그들의 보증·지원을 받지 않습니다. 제품명과 상표는 각 소유자의 것이며, 호환 대상을 설명하기 위해서만 씁니다. 장치 통신 방식은 공개 문서가 아니라 사용자 본인 장치에서 관찰한 내용을 정리한 것입니다.

Creator Micro 2 키보드를 위한 macOS 메뉴바 앱입니다. Orca에서 돌아가는 AI 에이전트 작업의 상태를 키 LED와 언더글로우로 보여 주고, 앞에 있는 앱에 따라 키 배치(레이어)를 바꿉니다.

## 하는 일

- **Orca 작업 칸**: 키 1~10이 Orca 작업 하나씩을 맡아 상태를 색과 움직임으로 보여 줍니다 (진행 중·승인 필요·답변 필요·오류·완료). 누르면 그 작업으로 이동합니다.
- **언더글로우**: 개입이 필요한 작업이 있는지 한눈에 보여 줍니다. 오류(빨강 깜박임)와 개입(주황·살구 숨쉬기)은 색이 다릅니다.
- **레이어**: 앱마다 키·노브·조이스틱 동작과 LED 색을 정합니다. 연결되지 않은 앱은 기본 레이어를 씁니다. 추천 프리셋(코드·브라우저·Zoom·미디어·iTerm·Notion)이 있습니다.
- **노브·조이스틱 화면 표시**, 노브 길게 눌러 레이어 고르기, 밤 시간 LED 어둡게, 모니터 지정 전체 화면 캡처 등.

## 필요한 것

- macOS (Apple 실리콘·Intel), Creator Micro 2 (USB 또는 Bluetooth)
- Orca (작업 칸을 쓸 때)
- 권한: 입력 모니터링, 손쉬운 사용, 화면 기록(캡처 동작을 쓸 때), System Events 제어

## 빌드

Node 24 이상이 필요합니다.

```
npm ci
npm test                 # 테스트 (장치·Electron 없이 돈다)
npm run app              # 개발 실행
npm run dist:dmg:local   # DMG — 임시(ad-hoc) 서명, 공증 없음. 인증서가 없어도 된다
npm run dist:dmg         # DMG — Developer ID 서명 + 공증 (키체인의 인증서와 notarytool 프로필 `output` 필요)
```

임시 서명 빌드는 다른 Mac에서 처음 열 때 "확인되지 않은 개발자" 경고가 뜹니다 (Finder에서 우클릭 → 열기). 다시 빌드하면 서명이 바뀌어 입력 모니터링·손쉬운 사용 권한을 다시 줘야 할 수 있습니다.
